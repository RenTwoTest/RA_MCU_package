# Renesas RA MCU Software

Welcome to the starting point for software development with **Renesas RA microcontrollers**.

The RA family is based on Arm® Cortex®-M processors and is supported by the Renesas Flexible Software Package (FSP).

Use this page to find the primary software package, example projects, development tools, operating-system resources, documentation, and support for RA MCU development.

## Flexible Software Package

The **Flexible Software Package** is the primary software platform for Renesas RA microcontrollers.

FSP provides:

- Board Support Packages
- Peripheral Drivers
- Middleware
- RTOS Integration
- Security Components
- Connectivity Software
- Configuration Tools
- Example Projects
- Documentation and Release Assets

📦 **Repository**  
👉 [Explore the Flexible Software Package](https://github.com/renesas/fsp)

## Operating Systems

RA microcontrollers support multiple embedded software development models.

### Bare Metal

Develop applications directly using FSP peripheral drivers, middleware, and configuration tools.

👉 [Explore FSP](https://github.com/renesas/fsp)

### FreeRTOS

FreeRTOS integration is available through the Flexible Software Package.

👉 [Explore FSP](https://github.com/renesas/fsp)

### Azure RTOS

Azure RTOS integration and middleware components are available in supported FSP releases.

👉 [Explore FSP](https://github.com/renesas/fsp)

### Zephyr RTOS

Renesas RA board, SoC, and driver support is developed through the upstream Zephyr project.

👉 https://github.com/zephyrproject-rtos/zephyr/tree/main/boards/renesas
